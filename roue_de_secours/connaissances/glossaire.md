- **Gabarit** : le fichier Excel du mois, préparé pour votre société, à télécharger puis remplir.
- **Déposer** : envoyer le fichier rempli pour contrôle ; rien n'est transmis au GIPAME à ce stade.
- **Brouillon** : fichier déposé et accepté, pas encore soumis.
- **Soumettre** : valider la déclaration ; c'est seulement là qu'elle compte.
- **Rapport de contrôle** : résultat du dépôt ; rouge = à corriger, orange = à vérifier.
- **Version** : chaque correction crée une nouvelle version ; les anciennes sont conservées.
- **Publication** : les totaux du marché d'un mois, provisoires puis définitifs.
- **« c »** : total confidentiel, masqué pour qu'on ne puisse pas reconnaître les ventes d'une société.
- **Couverture** : part des membres attendus qui ont déclaré un mois donné.
- **Segment** : type de véhicule dans la grille du GIPAME (citadines, SUV, pick-up, bus, camions…).
